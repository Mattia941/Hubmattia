# HubItems Plugin Spigot/Paper

Plugin completo per la gestione del mondo `HUB` su Minecraft.

## Struttura del Progetto (Maven)
- `pom.xml`: File di configurazione Maven per la compilazione.
- `src/main/resources/plugin.yml`: File di configurazione del plugin Minecraft.
- `src/main/java/com/hubitems/HubItems.java`: Codice sorgente principale.

## Come Compilare
Esegui il comando Maven nella cartella del progetto:
```bash
mvn clean package
```
Troverai il file `.jar` generato nella cartella `target/`.
